# Glossar

> **Zielgruppe:** Alle Leser, besonders Einsteiger.
> **Zweck und Lernziel:** Projektbegriffe einheitlich verstehen.
> **Voraussetzungen:** Keine.
> **Kanonisch für:** Begriffsdefinitionen der accura-Dokumentation.
> **Verwandte Dokumente:** [Dokumentationsindex](../README.md), [Grundlagen](../grundlagen/web-und-pwa.md)

| Begriff | Bedeutung in accura |
| --- | --- |
| ADR | Architecture Decision Record; nachvollziehbare Entscheidung mit Kontext und Folgen |
| Allowlist | genau eine serverseitig erlaubte, verifizierte Google-E-Mail |
| Appearance | lokale Wahl von Modus, Farbquelle, Palette und Tokens |
| CSRF | fremd ausgelöste authentifizierte Anfrage; durch Origin plus Sitzungstoken abgewehrt |
| Finance Data Schema v1 | Tabellenvertrag der zehn Maschinen-Tabs |
| Golden Screenshot | committed Referenzbild für visuelle Regression, keine Produktdokumentation |
| Integer-Cents | Geldrepräsentation als ganze Centzahl statt Gleitkomma-Euro |
| Last-known-good | zuletzt vollständig validierter Finance-Snapshot im Browser |
| Maschinen-Tab | underscore-präfigierter Sheet-Tab mit exakt definierten Spalten |
| Nonce | Zufallswert, der ein ID-Token an eine OAuth-Transaktion bindet |
| OAuth | delegierter Google-Zugriff ohne Übergabe des Google-Passworts an accura |
| PKCE | Bindung des Authorization Code an einen geheimen Verifier |
| PWA | installierbare Web-App mit Manifest und Service Worker |
| Privacy-Modus | visuelle Maskierung von Geldwerten; keine Verschlüsselung |
| Provider | React-Komponente, die Context-Werte für Nachfahren bereitstellt |
| Selector | reine Funktion, die Domänendaten auswählt oder berechnet |
| Shoulder Surfing | beiläufiges Mitlesen sichtbarer Informationen durch Umstehende |
| Single Source of Truth (SSOT) | genau eine kanonische Vollbeschreibung je Thema |
| Snapshot | datierter Zustand eines Kontos, Pockets oder einer Schuld |
| stale/veraltet | vorhandener gültiger Stand, dessen aktuelle Synchronisierung fehlt |
| View-Model | aus Domänendaten abgeleitete, UI-fertige Struktur |
| Vercel Function | serverseitiger same-origin API-Handler unter `api/` |
| Web Worker | separater Browser-Thread für lokale Bildfarbanalyse |
